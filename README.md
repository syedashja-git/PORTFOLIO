# Syed Ashja Portfolio

A responsive, buildless HTML/CSS/JavaScript portfolio.

## Run
Extract this ZIP and open index.html in your browser. No install or build is required.
Optional local server: python -m http.server 8000

## Deploy
Upload index.html, assets/ and LICENSE to your hosting root (e.g. public_html), or deploy this folder as a static website on Vercel or Netlify. No build command is required.

## Edit
- index.html: profile, contact links, projects and skills.
- assets/style.css: original vCard template styles.
- assets/custom.css: portfolio customizations and responsive layout.
- assets/script.js: navigation, animated skill bars, filters and image preview.
- assets/project-0.png through project-5.png: original project covers from the supplied Drive folder.

The contact form posts to FormSubmit and delivers inquiries to infosyedashja@gmail.com. Before production use, submit the hosted form once and activate it using the FormSubmit confirmation email sent to that inbox. Submit again after activation to test both delivery and the visitor acknowledgement. reCAPTCHA must stay enabled and the form must use normal POST (not AJAX) for autoresponse support. FormSubmit requires an HTTP(S) page, not a file:// page. No SMTP password is included. Email delivery has not been verified in an inbox. Project cards preview images; live project URLs were not supplied. Google Fonts needs internet access; a sans-serif fallback is provided.
